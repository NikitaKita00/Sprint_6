- `pages/` — содержит классы страниц с методами взаимодействия (Page Object модели).
- `locators/` — содержит классы с локаторами элементов для соотвествующих страниц.
- `tests/` — содержит тестовые файлы с кейсами, использующими Page Object и локаторы.
- `test_faq.py` - содержит Выпадающий список в разделе «Вопросы о важном»
- `test_order.py` - содержит Заказ самоката. Нужно проверить весь флоу позитивного сценария с двумя наборами данных
